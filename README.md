# CSharp-Training-APIs

# 🚀 .NET Backend & API Learning Journey

Welcome to my personal learning and portfolio repository! As a full-stack developer transitioning towards robust backend engineering, this repository documents my practical transition from monolithic (MVC) architectures to modern, scalable **RESTful Web APIs** tailored for the Azerbaijani and global software markets.

## 🛠️ Tech Stack

- **Language:** C#
- **Framework:** ASP.NET Core Web API (.NET)
- **ORM:** Entity Framework Core (EF Core)
- **Database:** PostgreSQL
- **Validation:** FluentValidation
- **Version Control:** Git & GitHub

## 📂 Projects Roadmap

## 🎯 Goal

The primary objective of this repository is to build production-ready, clean-architecture-based APIs, implement enterprise-level validation, proper error handling, and master database relations to align with modern enterprise backend requirements.
